# 核心驱动：目标、取舍与持续改进

五步法、第一性原理和帕累托原则共同决定系统朝哪里推进、把精力放在哪里，以及怎样修正偏差。它们既用于项目开始前的规划，也用于执行中的判断。

## 五步法：从问题回到改进

**目标 → 问题 → 诊断 → 方案 → 践行**，再根据执行结果进入下一轮。

| 环节 | 需要回答的问题 |
|---|---|
| 目标 | 希望得到什么结果？ |
| 问题 | 当前结果与目标之间，具体差在哪里？ |
| 诊断 | 差距由什么造成？证据是什么？ |
| 方案 | 应改变哪个环节，如何判断改变是否有效？ |
| 践行 | 执行方案，观察结果，检验原来的判断 |

区分“问题”和“诊断”很重要。推进缓慢是一种表现；任务过大、知识缺口、说明含糊或状态下降，才是需要分别检查的可能原因。原因不同，对应的调整也不同。

**反复出现的问题，或已经明显妨碍推进的问题，是启动诊断的信号。** 普通波动可以等到一个执行单元结束后回看，避免尚未获得足够反馈就频繁改方案。

## 第一性原理：持续抓住根本目的

在这套系统中，第一性原理首先用于追问：**这件事最终要解决什么问题，哪些约束必须满足，当前行动为什么有必要？**

项目目标构成主干。阶段任务、学习内容与工具选择，都应能说明它们如何服务于主干。更长期的价值追求则用于检查：这个项目本身是否仍值得投入。

例如，DFT 复刻的核心目标是学习计算材料研究方法。因此，学习重点放在材料机制、核心算法、数据流与结果判断上；代码实现细节按实际需要投入，部分工作交给 Agent 完成。具体分配见 [02 · 科研学习系统](../02-Research-System/README.md)。

目标提供取舍依据，事实与约束决定方案是否成立。目标值得追求，并不能替代对方法和结果的检验。

## 帕累托原则：集中投入关键少数

一个任务可能包含大量可做的事，但它们对当前目标的贡献并不相同。**优先解决决定能否推进、能否判断结果的关键问题。**

选择投入重点时，可以依次判断：

1. 缺少这部分理解或工作，是否会妨碍下一步推进，或影响结果判断？
2. 当前需要掌握到什么程度？哪些细节可以延后或委托？
3. 继续投入，是否仍比处理其他关键问题更有价值？

“20%”用于提醒关注关键少数，实际贡献比例和投入重点需由任务与反馈判断。结果校验等必要工作，也应纳入关键投入。
