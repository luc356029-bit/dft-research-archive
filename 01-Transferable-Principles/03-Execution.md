# 具体执行：理解信息、恢复状态、保留思路

有了目标和推进路线，执行仍可能被信息过载、疲劳与频繁切换打断。笔记法处理信息，休息原则处理持续受阻时的状态，思路存储保存想法与任务进度。

## 笔记法：及时整理和内化信息

**在恰当的时候梳理、内化一部分知识，再继续接收新信息**，是笔记法的核心。笔记既辅助思考、理清思路，也保存经过理解、按自己的思路压缩后的信息。

阅读网课或 LLM 讲解时，若读到后面已经忘了前面的关系，或理解开始吃力，可以用纸笔勾画关系、分步写出思路，把刚接收的内容重新组织起来。仍有疑问，就回到材料或讲解中解决；能够顺利理解时，可以省去纸笔辅助。

随后，将有价值的内容清晰简洁地记到电脑上。**电子记录也是进一步整理和内化的过程**，同时便于长期保存、检索和构建知识库。纸笔主要辅助即时思考，记录不宜过密，以免记录本身增加负担。

## 休息原则：持续受阻时，先恢复再判断

**当持续投入已难以产生进展，且思路越来越混乱时，先暂停当前问题。** 放下任务、做放松活动，再回来看已有内容，重新整理关键关系。

恢复后需要区分原因：

- 如果原有关系已经清楚，可以继续推进。
- 如果仍缺少关键知识或证据，应补足缺口。
- 如果同一问题反复阻塞任务，应回到系统架构或目标层面检查。

## 思路存储：保存想法，也保存继续工作的入口

### 暂存新想法，保护当前任务

执行 A 时想到 B，先记录 B。**通常先完成 A 的最小闭环，再决定是否转向 B。** 如果新信息已经推翻 A 的前提，则应及时调整，无须为完成原计划而继续。

### 记录进度，降低重新开始的成本

如果待办清单只写任务名称，仍可能让下一次启动变得困难。在接下来一两个小时或半天内，保留少量明确的拟推进任务，并记录：

**当前做到哪里 → 已确认什么、卡在哪里 → 下一步做什么。**

需要切换任务时，先保存这个入口；任务间隙再根据重要性选择下一项。这样既保留新想法，也避免每次重新梳理整个项目。

### 利用 LLM 等待时间，按依赖关系安排任务

LLM 执行期间，先形成初步思路，再决定继续当前任务还是切换。初步思路不必完整，但应包括已知条件、可能解释和待核对的问题。

| 当前问题 | 等待期间的安排 |
|---|---|
| 较简单 | 自行思考，再与回复对照 |
| 较复杂，但后续步骤不依赖它 | 记录思路与待答问题，继续不受影响的步骤 |
| 较复杂，且后续步骤必须等待它 | 保存当前进度，转向另一项可独立推进的任务，优先考虑相关任务 |
