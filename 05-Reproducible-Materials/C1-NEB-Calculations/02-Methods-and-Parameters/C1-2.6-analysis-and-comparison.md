## 2.数据处理

1. **D（T）推导出 Ea**

```math
D(T)\propto a^2\Gamma(T)，即 ，D(T)\propto a^2\nu e^{-E_m/k_BT}
```

其中，a为跳跃距离；
将与 T 无关的系数合并，单种扩散路径的情况：

```math
D(T)=D_0e^{-E_m/k_BT}
```

多种扩散路径时，整体扩散还受路径连通性和回跳相关性影响。
本项目通过 KMC 得到整体 D(T)，再拟合表观活化能。
单路径变为整体扩散，对象由 Em 变为 Ea ；
不同的扩散路径的Em对于 D(T) 的贡献随着温度变化产生不同变化，
总体 D(T) 不一定严格符合单一指数关系，
目前250-400K的温区内，通过拟合得到一个代表性的前因子 ，写为 $`D_{fit,0}`$ ：

```math
\boxed{D(T)≈D_{fit,0}e^{-E_a/k_BT}}
```

一个 D(T) 对应 $`D_{fit,0}`$、Ea 两个未知量，
引入ln，各温度数据形成拟合直线，求斜率即可算出 Ea ：

```math
\boxed{\ln D=\ln D_{\mathrm{fit},0}
-\frac{E_a}{k_B}\frac1T}
```

C1 2.5 通过KMC得到的MSD和t计算出对应温度的D，代入上面的lnD中。

2. **处理流程：**
**各温度的 KMC 输出 → 汇总 $`D_{\mathrm{Li}}(T)`$ 及统计误差 → 转换为 $`1/T`$ 、$`\ln D`$ → 拟合斜率 → $`E_a=-mk_B`$**
Em 是某次具体跳跃的能量门槛，
Ea 表示 D 随温度变化的程度，Ea 越大，D 对温度变化越敏感。
本次模拟使用 250、300、350、400 K 的 Li 示踪扩散系数，并让统计误差较小的数据点具有更高拟合权重，得到：

```math
E_{a,\mathrm{Li}}^{250\text{–}400\,\mathrm K}
\approx0.25161\ \mathrm{eV}
```

但这是该温区内的表观活化能，不是证明所有温度下都存在一个完全不变的总体能垒。

3. **$`\nu`$ 取值的影响：**
如果 $`\nu`$ 扩大10倍，lnD 扩大为 lnD+ln10 ，纵轴扩大，但斜率不受影响，Ea 不受影响
## 3.与文章方法差异

1. **文章方法：**
先估算第 i 类路径的 $`D_i(T)`$ ，再加权得到总$`D(T)`$ ：

```math
D_i(T)=\frac{Zg}{2d}a_i^2\nu
\exp\left(-\frac{E_{a,i}}{k_BT}\right)，即，
D_i(T)=\frac{Zg}{2d}a_i^2\Gamma_i(T)
```

其中，$`E_{a,i}`$ 为第 i 类路径的能垒（注意文章写的不是$`E_{m,i}`$）；$`a_i`$ 为第 i 类路径的跳跃距离；
Z为配位数；g为结构因子。Z、g 用于修正晶体几何结构的影响。
加权得到总 $`D(T)`$ ：

```math
D(T)=\sum_i\frac{N_i}{N}D_i(T)，①
```

其中，N为无向边（扩散路径）总数；Ni 为第 i 类的无向边数。
文章还引入了包含 Ea 的 $`D(T)`$ 式：

```math
D(T)=\frac{Zg\nu}{2d}a^2e^{-E_a/k_BT}，②
```

其中，a 为平均跳跃距离，Ea 为活化能。
联立①和②，得到 Ea 计算公式：

```math
{
E_a=-k_BT\ln\left[
\sum_i\frac{N_i}{N}
\frac{a_i^2}{a^2}
e^{-E_{m,i}/k_BT}
\right]
}
```

（注意，文章 Ea 公式多打了一个 $`\nu`$ ，如果有 $`\nu`$ 会导致量纲不一致 ）

2. **与文章对照：**
文章 LiSi Npath = 1，因此只能与文章进行有限的对照：
**目前方法：NEB → 各类 path 能垒 → KMC → MSD和对应 t → $`D(T)`$ → 线性拟合 → Ea**
**文章方法：NEB → 各类 path 能垒 → 结构与各路径能垒、数量、跳跃距离求 $`D(T)`$、Ea 的加权公式 → $`D(T)`$、Ea**

| 活化能       |                      0.25161 eV |                  0.268 eV |
| $`D_{300}`$ | **$`2.0123\times10^{-9}`$** cm²/s | $`2.28\times10^{-9}`$ cm²/s |

## 5.差异分析：
### 为什么与KMC差这么多、与文章数据差这么多？

1. 先**从Npath取值方向思考：**
考虑到文章 Npath=1 ，分别取四种路径进行了计算：

| Path    | $`E_a`$(eV) | $`Z_i`$ | $`D_{300k}`$ (cm²/s)    |
| ------- | --------- | ----- | --------------------- |
| 0       | 0.253444  | 1     | $`6.688\times10^{-8}`$  |
| 1       | 0.235830  | 2     | $`3.122\times10^{-7}`$  |
| 2       | 0.245909  | 1     | $`1.070\times10^{-7}`$  |
| 3       | 0.427661  | 2     | $`2.033\times10^{-10}`$ |
| 论文 LiSi | 0.268     | \     | $`2.28\times10^{-9}`$   |
- 差异仍然较大。**作者取 Npath=1 本身就有疑点，**
**选择KMC的扩散路径时的数据**（path0-3，扩散路径端点直线距离越来越长。cutoff选取第4距离壳）：

| 保留路径     | 周期网络的长程连通维度 | 结果          | 长度       | 能垒       | KMC总迁移次数占比 |
| -------- | ----------- | ----------- | -------- | -------- | ---------- |
| Path 0   | 0D          | 只能在有限位点间交换  | 2.694958 | 0.253444 | 15.889%    |
| Path 1   | 0D          | 只能在有限位点间交换  | 2.928474 | 0.235830 | 62.809%    |
| Path 2   | 0D          | 只能在有限位点间交换  | 2.946003 | 0.245909 | 21.265%    |
| Path 3   | 1D          | 可以沿一个方向长程迁移 | 3.053855 | 0.427661 | 0.038%     |
| Path 0＋1 | 3D          | 已形成完整三维连通网络 | \        | \        | \          |
- KMC总迁移次数占比并不能反应某类path算出的 Di 是否能够代表材料整体 D，
但**当 Npath=1 且需要足够具有代表性，就需满足：**
**该类path能独立形成三维长程扩散，且承担主要的长程输运。
路径类别数 应该通过 长程连通性＋扩散结果收敛性 来确定**
- **论文 Npath=1 的核心疑点：**
没有证据证明所选单类路径既满足必要的长程连通性，又能够代表材料的整体扩散行为。
如果作者的结果只是某个局部扩散网络的结果：

```math
\text{位移范围有限}
\;\Rightarrow\;
\mathrm{MSD}(t)\text{不会无限增长}
\;\Rightarrow\;
D_{\mathrm{长时间}}
=\lim_{t\to\infty}\frac{\mathrm{MSD}(t)}{6t}=0
```

- 目前来看：
path0-3，没有一个能够作为唯一path代表整体D，如果作者选的是我们没有计算的path4、5、6，可能更局限，
path3的长度下能垒快速增加，path4、5、6，更长，很有可能有原子阻挡，能垒更大。
而对于三维长程扩散来说，即便 path4、5、6 可以形成三维长程扩散，path0、1 的组合能垒也会低很多，
这导致 path4、5、6 几乎不会是承担主要长程输运的path，因此文章 Npath=1 的结果不作为准确性基准
**因此：文章 LiSi 的数据参考价值较低，但方法任然值得学习、核验**
### 为什么与KMC数据差这么多？

2. **从迁移距离统计角度入手的发现：**
在KMC模拟之后，有两种口径可以计算D：
A 均方距离、t → D300k
B 均方位移、t → D300k （也就是C1 2.5的方法）

| 同一套300 K数据               |            $`D`$（cm²/s） |
| ------------------------ | ----------------------: |
| 当前论文式公式直接代入              | $`4.862086\times10^{-7}`$ |
| **由KMC实际事件计数、跳距计算的统计 A** | $`1.568409\times10^{-8}`$ |
| **由已有KMC分块结果重新汇总的统计 B**  | $`2.012311\times10^{-9}`$ |
- 数值上发现，A÷7.8 = B，原因在于 A 算的是迁移路程，**没有考虑到原子往回迁移的情况**；
- 通过文章方法计算出来的 D300k ，÷31之后，恰好又是 A 的结果，
原因在于，同一时刻，只有一个 Li 原子会和空位交换而迁移，而其余30个 Li 原子不迁移，
我们算的 $`\Gamma_i(T)`$ 为单个 Li 与空位的交换速率，而**文章公式在 g=1 时并非建立在单个 Li-空位 迁移模型基础之上。**
**如果在当前 g=1 的情况下，公式算出来的是所有原子都迁移的情况；**
**但如果 g=1/31（引入空位模型情况），结果就准确等于 统计A
（虽然数值上成立，但用g修正空位模型，理论上不算合适）**

##### 2. DLi——参考[kirsch文章](https://doi.org/10.1088/2515-7655/ada639)
将我们的KMC模型与 kirsch 的情况对其：
双方都为晶态 LiSi、800 K、128 个 Li 位点中有 1 个空位

| 结果          |              Li 扩散系数，cm²/s |
| ----------- | -------------------------: |
| 本项目 KMC     | (2.67672 ± 0.01258) × 10⁻⁷ |
| Kirsch AIMD |                 1.0 × 10⁻⁷ |
**差异分析：**

1. **能垒差**——替换能垒，观察变化
保持 “晶态 LiSi、800 K、128 个 Li 位点中有 1 个空位” 的模型不变，尝试频率 10¹³ s⁻¹，替换原能垒：

| 改变的输入 | Li 示踪 D 相对基线的变化 |
|---|---:|
| 只替换 Path00 能垒 | +22.23% |
| 只替换 Path01 能垒 | −10.38% |
| 只替换 Path02 能垒 | −1.47% |
| 三条同时替换 | +3.22% |
- 结论：能垒变化对 D 差异影响有限

2. **不常发生的 path03 影响**——去掉不常发生的 path03 ：

| 模型              | DLi                | 变化      |
| --------------- | ------------------ | ------- |
| 原模型             | 2.677 × 10⁻⁷ cm²/s | /       |
| 原 Em 不算 Path03  | 1.798 × 10⁻⁷ cm²/s | −32.84% |
| 文献 Em 不算 Path03 | 1.890 × 10⁻⁷ cm²/s | −31.58% |
- 结论：
path03对结果有较大的影响，虽然 path03 只在原项目KMC中迁移次数占比0.038%（300k时），却产生30%影响（800k时），path03可能较大程度改变了迁移路径相关性，帮助空位逃离某些区域，减少回跳。
但只能说明我们的数据比文献大，没有 path03 会让 D 减小，还不足以说明和文献的差异来自 path03

3. **$`\nu`$ 取值的影响**
通过kumar文章的振动能量曲线，反推出 $`\nu`$ ≈ 3.49–6.92 × 10¹² s⁻¹
如果： $`\nu`$×0.4 → Δt（等待时间）×2.5 → D×0.4 → 2.67672 × 10⁻⁷ ÷ 2.5 ≈ 1.07 × 10⁻⁷ cm²/s
D 接近 Kirsch 1.0 × 10⁻⁷ 的数据。
结论：
 $`\nu`$ 取 $`10^{13}`$ 可能会导致结果偏大

4. **跳跃失败情况的影响**
当前的速率计算未考虑到 Li 跳出，越过鞍点但未成功到达空位又返回起始点的情况。
这种情况可能会使计算时间较真实值短，因而算出的 D 会比实际值偏大。
结论：
跳跃失败情况是可能的原因，但目前还不足以证明跳跃失败的情况对 D 产生了较大影响
