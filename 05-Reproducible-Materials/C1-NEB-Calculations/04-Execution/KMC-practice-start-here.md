# C1 2.5 → 3.实践

## 目的与范围

复用既有 LiSi 首轮、32个Li位点、31个Li和1个空位、300 K的结果，核对：

**已核验NEB能垒 → 跳跃速率与候选事件 → 位置/时间更新 → 分块统计 → D_Li。**

本包从对话中已提供的 `02_输运网络_后处理脚本_输入与证据.zip` 摘取原始文件，逐文件与原 `MANIFEST.json` 的 SHA-256 核对；原始字节未修改。它不是新一轮云端更新，也没有新增DFT或正式KMC模拟。`文件来源.json` 保存每个副本的原归档位置和校验值。

核查脚本只用Python标准库，不需安装NumPy、ASE或VASP；不联网、不提交作业、不修改原始数据。以下命令在解压出的本文件所在目录运行。

## 第一步：输入、速率与候选事件

先运行：

```powershell
py .\核查KMC.py
```

它会输出真实模型条件、四类能垒和复算速率，以及空位在0号位点时的6个候选事件。默认只执行这一步。

对照打开 `原始数据/KMC_ext_00.json`，先只找这些字段：

| 字段 | 含义 |
|---|---|
| `T_K` | 温度，当前300 K |
| `attempt_frequency_s` | 假设的共同尝试频率，1e13 s^-1 |
| `nsites`、`Li_count`、`vacancy_fraction` | 32个位点、31个Li、空位比例1/32；不是32个Li再额外加31个Li |
| `barriers_eV` | path 0—3 的迁移能垒，沿用本轮对称化Efr口径 |
| `supplied_neighbor` | 按当前空位所在位点，查可交换的邻居位点 |
| `supplied_rates_s` | 与邻居表一一对应的单事件跳跃速率 |
| `supplied_displacement_A` | 空位沿对应边的未折回位移，单位Å；迁移Li的本步位移方向相反 |

表的行号从0开始。`supplied_neighbor` 第一行是 `[18,22,26,14,7,8]`：空位在0号位点时，这六个位点上的Li可以跳入它。程序按速率权重选择，并非均匀六选一，也不是直接四选一。

**先确认：path 0的能垒接上了NEB；能解释为什么有4类路径、6个具体事件。** 不需要逐行看32个位点的数组。

## 第二步：只演示一次状态更新

第一步理解后运行：

```powershell
py .\核查KMC.py --step 2
```

本步使用真实网络，但人为指定两个随机数为0.5。它是教学示例，不是原计算的第一跳或历史轨迹回放。输出候选事件选择、等待时间、Li与空位的相反位移、新空位位置。例子初始Li身份号与所在位点号一致；交换后不再一致。

**核查重点：空位0→26，同时原位点26的Li移到0；下一步应查第26行候选事件。** 不把一次事件用于判断长期D。

## 第三步：由归档的分块数据复算300 K汇总

```powershell
py .\核查KMC.py --step 3
```

主结果来源为 `KMC_ext_00.json`（seed 137）和 `KMC_ext_02.json`（seed 991）。两者各统计800万次交换、160块，每块5万次；各有2万次预运行不计入统计。这里的时间是模型中的经过时间，不是电脑运行耗时。

原模拟每块利用每个Li的净位移计算 `D_b = MSD_b/(6*t_b)`，最终按 `sum(D_b*t_b)/sum(t_b)` 汇总。原数据内部D单位为Å²/s，转为cm²/s需要乘1e-16。

**数据边界：本归档保留每块的D与时间，没有在这些JSON中保存每次跳跃的原子坐标。本脚本复算分块汇总，并非从独立逐跳坐标重新得到MSD。** 逐跳累计位移和MSD的实现可在 `原始代码/tracer_kmc.py` 中对照。

预期汇总为 `D_Li = 2.012311292523e-09 cm²/s`；估计的KMC 1SE约 `1.967569586e-11 cm²/s`。不要再乘一次空位比例。

`KMC_ext_01.json` 与 `KMC_ext_03.json` 是同种子轨迹采用320块的对照，不能和160块结果当成独立新轨迹一起汇总。分块对照沿用 `correlation_error_supplement.json` 的相关误差补充，不假设同一轨迹的两种分块互相独立。

脚本复算单种子/双种子D、对应标准误差、种子对照、32位点的分块对照及逐边事件覆盖。没有重新审计128位点、其他温度、DFT尺寸或模型的物理真实性。标准误差计算细节可暂不深究，先能理解其用途。

## 文件角色与历史状态

`原始数据/transport_model.json` 是网络与能垒来源。`KMC_ext_*.json` 是单次模拟输入与分块结果。`KMC_statistical_admission.json` 与 `correlation_error_supplement.json` 是统计验收及补充；`finite_model_final_admission.json` 是本轮有限模型最终范围证书。

旧文件的 `PENDING` 字段仍是当时生成的阶段状态；保留原始字节，因此没有改成PASS。是否最终通过，要结合后续证书及其SHA关联判断。最终证书仍保留当时的资源待办字段；本包只核查科学结果部分，不评估资源或监测当前状态。

`原始代码/` 为未改动的生产代码摘录，帮助定位实际算法；其中有历史绝对路径和外部依赖，不作为本教学包的直接运行入口。请只运行根目录 `核查KMC.py`。
