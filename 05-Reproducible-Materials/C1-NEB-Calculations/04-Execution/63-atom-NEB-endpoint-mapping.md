# endpoint_mapping.py：代表路径如何映射为63原子NEB初末态

整理日期：2026-10-31。索引全部从0开始。本次复核已有结构和算法，没有新跑DFT。

上游 prepare_vacancy_seed.py 先从64原子宿主删除Li槽位0，保留其余63个宿主槽位的身份。对母胞代表边(i,j,S)，用向量 (f_j+S−f_i) @ A_parent 定位周期像，再通过 supercell_mapping.json 的母胞身份筛选，找到超胞中的目标Li槽位。空位运动为0→target，实际迁移Li沿相反方向target→0。

未弛豫种子只把迁移Li移到空位，不能直接当已验证端点。正式调用者 prepare_defect_checks.py 读取已弛豫且经过SCF、力、输入关联和k网格检查的A端CONTCAR，再调用 endpoint_mapping.equivalent_endpoint。k4版本A源目录为 hpc/results/20261014-171257-b59fb640bbc6/20261014-175030-f246bfc86cd7。

构造过程如下：

1. audit_assignment按物种分别以PBC最小像距离构建代价矩阵，并用匈牙利算法做全局一对一分配，检查A的身份仍对应宿主槽位1…63，且仅Li槽位0缺失。
2. 把A中每个原子相对对应理想宿主槽位的弛豫位移取最小像，并转为分数坐标delta。
3. 枚举完整超胞空间群操作(R,t,perm)，只接受perm[0]=target的操作，即把整个空位配置映射到目标空位，而不是只移动一个Li。
4. destination_host_slots仅把迁移Li的目标槽位由target改为0。通过perm的逆映射求 source_atom_permutation，从A中提取正确的弛豫位移，按 delta[src] @ R.T @ cell 旋转，叠加到目标宿主槽位上。平移t已包含于宿主槽位置换，不再重复加一次。
5. 将B各原子位置展开到相对A的最小像；扣除Si平均刚体漂移。若有多个等价操作，选择非迁移原子总位移平方最小者。
6. 保持A/B原子顺序、物种和晶胞一致；再次做身份分配及最小原子距离检查，写出POSCAR.A及POSCAR.B00…B03，准备独立DFT端点验证输入。

表中的迁移Li端点距离包含缺陷弛豫和整体对齐效应，不等同于母胞理想Li-Li距离，也不是NEB相邻图像距离。原始JSON还保存每条路径R、t、完整槽位置换、63个原子的源置换和逐原子位移。

NEB要求相同索引代表同一个原子。仅独立删除另一个Li后重新排序，容易把原子交换或晶胞跨界错误写入插值；本方法显式保留迁移Li身份并对其余原子做同物种重标记，得到同一完整构型的对称端点。该操作不等于已求出最小能量路径：还须普通NEB、CI及力/参数验收。

能量等价还要求超胞边界、实际k网格及哈密顿量支持同一操作；不能仅凭PBC或原始母胞对称性断言等价。已有2026-10-27正反向审计核对了这些条件及实际端点输出。对真正不等价的端点，应保留各自能量和正反势垒，不能直接平均。

本次在内存从已有POSCAR.A重新生成全部四个B，逐坐标对照已保存POSCAR.Bxx，均误差<1e-10 Å，身份分配全部通过。生成JSON内的 REQUIRES_DFT_CHECK 是历史生成状态，不冒充后续DFT通过证书。共同证据ZIP附原始映射、A/B结构、调用者、依赖与2026-10-27审计JSON，保留各阶段证据边界。
