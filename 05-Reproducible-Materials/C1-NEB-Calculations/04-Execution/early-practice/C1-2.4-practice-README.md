# C1.2.4 · Path00 的 NEB 参数与能垒读取

LiSi 的计算链为：端点准备 → 线性插值与 IDPP → 普通 NEB → CI-NEB → 收敛核查。此处记录正式四路径模型中 Path00 的四中间图像结果。

## 输入与参数

`00`、`05` 为端点，`01—04` 为中间图像，共六套 Li31Si32 结构。CI 起始结构继承普通 NEB 已优化的带，并非最初的直线插值。

| 参数 | 本段设置 | 含义 |
|---|---|---|
| IMAGES | 4 | 中间图像数，不计端点 |
| LCLIMB | .TRUE. | 启用爬山图像 |
| SPRING | −5 | 弹簧参数 |
| EDIFF | 1E−7 eV | 整个计算体系的电子收敛阈值 |
| EDIFFG | −0.02 eV/Å | 力收敛阈值，按相应 NEB 投影/有效力核查 |
| NSW | 24 | 本段优化步数上限，并非已完成步数 |

当前入口：[运行元数据](../path00-CI/neb_metadata.json)、[NEB 分析](../../06-Validation/neb_analysis.json)、[普通 NEB 分析](../../06-Validation/ordinary_NEB_analysis.json)、[源文件索引](../../06-Validation/NEB-source-file-index.json)。

## 能量与收敛核查

原始 OUTCAR 与 vasprun.xml 是能量证据，分析 JSON 是其后处理记录。端点输出来自独立端态计算，未在该段 NEB 中重新优化。CONTCAR 是否对应最后已求能/力的构型，需要逐例核对。

统一采用完整离子评价帧的 Efr/TOTEN，并与 XML 末帧比较；Efr、无熵能与 E0 不能混用。这里的 Efr 是电子展宽能量口径，并未计入晶格振动熵。

正反能垒分别为 E峰−EA 与 E峰−EB；原模型在端点对称关系核查后采用 E峰−(EA+EB)/2。几微 eV 的差异来自该数值对称化。

本段全带最大投影力约 0.010787 eV/Å，满足 0.02 阈值，未达到 0.01 的全带阈值。更严格四图与六图控制另行记录。[能量读取脚本](../../03-Code/C1-2.4-check-NEB-energy.py)展示解析方法；原始逐图输出需结合源文件索引查找。

方法参考：[VASP NEB](https://vasp.at/wiki/index.php/NEB)、[VTST CI-NEB](https://www.henkelmanlab.org/vtsttools/neb.html)、[POSCAR](https://vasp.at/wiki/POSCAR)、[EDIFF](https://vasp.at/wiki/EDIFF)、[EDIFFG](https://vasp.at/wiki/EDIFFG)。
