# C1.2.3 实践包｜候选跳跃与周期连通

**目的：使用Codex的真实宿主结构与原始路径/拓扑报告，核验“16原子宿主 → 几何边 → 4类路径 → 三维候选网络”。** 不重新运行VASP、NEB或KMC。

## 文件来源

从已归档 `02_输运网络_后处理脚本_输入与证据.zip` 中直接提取，**以下三份原始文件保持字节不变**：

- `01_16原子宿主结构/POSCAR`：Codex用于分类的优化并对称投影后的LiSi参考晶胞（8Li+8Si）。
- `02_候选路径分类/projection_report.json`：`candidate_orbits`字段是已归档的完整周期像与空间群等价路径分类。
- `03_周期网络连通性/complete_orbit_connectivity_INTEGER.json`：周期边连接及跨周期整数拓扑核验。注意此为**几何拓扑**，不含NEB能垒。
- `核查路径.py`：独立从`POSCAR`读取晶格矢量与Li分数坐标，逐一枚举周期像并复算Li–Li几何边与距离，**无需安装第三方库**。对称归类、严格整数连通性本身直接与原始Codex报告核对，脚本不假装重新推导空间群或拓扑算法。

## 第一步：几何路径与4类等价路径（预计15—25分钟）

1. 打开`01_16原子宿主结构/POSCAR`，确认元素数量`8 8`和`Direct`坐标：这里只用前8行Li坐标作节点。
2. 打开`02_候选路径分类/projection_report.json`，找到`candidate_orbits`：读取`cutoff_A`、`n_undirected_edges`、`n_directed_edges`、`orbits`下的`path_id`、`Ni`、`representative`、`members`。
3. 每条`representative = [i,j,Rx,Ry,Rz]`，表示从晶胞中的Li_i指向周期像 `R=(Rx,Ry,Rz)` 中的Li_j。其距离是位点间直线距离，不是NEB迁移路径的弧长。输出`members`为对称等价的**无向**几何边集合，不能直接当作单次NEB计算次数。
4. 在本解压文件夹打开PowerShell运行：

   ```powershell
   py .\核查路径.py
   ```

## 第二步：连通性（第一步核验后再做）

运行：

```powershell

```

利用**原始整数拓扑报告**阅读以下组合的`component_count`、`components[].translation_rank`和`single_connected_3d_periodic_graph`：`[0]`、`[1]`、`[3]`、`[0,1]`、`[0,2]`、`[0,1,2,3]`。

**请回答：** 为什么Path00单独不是长程扩散，00+01却能形成三维？为什么00+02的两个1D分量不能算成2D？

完成两步即可结束本节，不重新学习B阶段全部对称性/周期图算法。

## 科学边界（请勿删掉）

- 3.3 Å来自本次选取前四个近邻壳层的有限模型；第5壳约4.225 Å，在4.3 Å才出现8条新增几何边。
- 第2壳（约2.928 Å）已经可以形成三维长程**几何**连通，因此3.3不是最小连通阈值。
- 能连通≠能垒低；几何筛选不能证明4类路径之外的机制都不重要。
- 本次离线枚举在已验证的本16原子LiSi晶胞范围内使用`[-2,2]^3`周期像；它不是适用于所有材料的普适邻居搜索算法。
- 2026-10-27 Codex新报告 `LiSi_3.3埃路径截断选择依据_20261027.md` 补充了不同半径的扫描；原归档的路径数据未因这一解释而修改。
