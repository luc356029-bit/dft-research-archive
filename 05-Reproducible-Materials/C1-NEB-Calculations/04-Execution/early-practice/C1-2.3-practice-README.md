# C1.2.3 · 候选跳跃与周期连通

本节串联 **16 原子宿主 → 周期几何边 → 4 类等价路径 → 候选迁移网络**。

| 材料 | 用途 |
|---|---|
| [宿主 POSCAR](16-atom-host/POSCAR) | 优化并对称投影后的 LiSi 参考晶胞，8 Li + 8 Si |
| [projection_report.json](../../05-Outputs/early-practice/candidate-paths/projection_report.json) | 候选路径、代表边、等价成员与截断半径 |
| [complete_orbit_connectivity_INTEGER.json](../../05-Outputs/early-practice/periodic-network/complete_orbit_connectivity_INTEGER.json) | 周期边连接、连通分量与整数拓扑 |
| [几何核查脚本](../../03-Code/C1-2.3-check-diffusion-paths.py) | 独立枚举周期像、复算 Li–Li 边与距离，并读取原拓扑报告 |

## 路径表示

`representative = [i,j,Rx,Ry,Rz]` 表示晶胞中 Li_i 到周期像 R 中 Li_j 的几何边。距离是两端点的直线距离，不是 NEB 路径弧长。`Ni` 统计对称等价的无向边，不能直接当作独立 NEB 计算次数。

分类字段位于 `candidate_orbits`；连通性可对照 `[0]`、`[1]`、`[3]`、`[0,1]`、`[0,2]`、`[0,1,2,3]` 的 `component_count`、`translation_rank` 与 `single_connected_3d_periodic_graph`。Path00 单独不能支持长程扩散，00+01 可形成三维网络；00+02 的两个一维分量也不能直接相加为二维。

## 截断与适用范围

3.3 Å 保留前四个近邻壳；第二壳约 2.928 Å 已形成三维几何连通，因此 3.3 Å 不是最小连通阈值。第五壳约 4.225 Å，截断扩大至 4.3 Å 时出现 8 条新增几何边。详细依据见[截断半径核查](../../../Supplementary-Validation/01-Internal-Consistency/LiSi-3.3A-cutoff-selection.md)。

几何连通性不含能垒信息，也不排除四类路径之外的机制。核查脚本的 `[-2,2]^3` 周期像范围仅用于本 16 原子 LiSi 晶胞，不作为通用邻居搜索保证。
