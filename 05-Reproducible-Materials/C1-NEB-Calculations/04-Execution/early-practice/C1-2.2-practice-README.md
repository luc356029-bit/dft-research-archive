# C1.2.2 · 结构与弛豫

本节展示 LiSi 从完整晶胞到单空位模型，再到 NEB 端点的结构准备过程。

| 顺序 | 结构与计算 | 输入和输出 |
|---|---|---|
| 1 | 16 原子 Li8Si8，全弛豫；ISIF=3、NSW=120 | [16-atom-relaxation](16-atom-relaxation/) |
| 2 | 64 原子 Li32Si32，SCF 单点检查；NSW=0 | [64-atom-single-point](64-atom-single-point/) |
| 3 | 移去一个 Li，得到 Li31Si32；固定晶格弛豫，ISIF=2、NSW=40 | [63-atom-vacancy-relaxation](63-atom-vacancy-relaxation/) |
| 4 | Path00 的 63 原子末态 B，单点 SCF 与受力核查；NSW=0 | [NEB-final-endpoint](NEB-final-endpoint/) |

64 原子步骤为单点检查，并非重新弛豫。64 与 63 原子模型使用相同晶格；缺陷模型只优化内部原子。

## 阅读与核查

通过 POSCAR 的元素与数量、INCAR 的 NSW/ISIF，以及 POSCAR 与 CONTCAR 的变化识别每一步。对应的 [analysis_result.json](../../05-Outputs/early-practice/) 保存 SCF 收敛、末帧受力与离子帧数；[数据读取脚本](../../03-Code/C1-2.2-inspect-relaxation-data.py)提供读取逻辑。

端点核查需确认 A 与 B00 的组成、晶格和原子排序一致，并检查 Li–空位交换后的能量与受力。进一步说明见[超胞构建](../64-atom-supercell-construction.md)与[端点映射](../63-atom-NEB-endpoint-mapping.md)。

这些材料来自首轮 LiSi 预验证，采用有限超胞和预设中性 Li 空位；其结果需在该模型条件下解释。
