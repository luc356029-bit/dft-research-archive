# C1.2.2 结构与弛豫：本人实践材料（只读副本）

目标：复核结构如何从完整晶胞变为缺陷计算模型，再形成 NEB 端点。重点是识别输入、操作、输出和收敛证据；不重跑 DFT，不改动原始输出。

## 材料对应关系

1. `01_完整晶胞16原子_全弛豫`：原始已执行宿主全弛豫（Li8Si8，16原子；ISIF=3，NSW=120）。
2. `02_完整超胞64原子_单点检查`：基于已弛豫宿主构建的64原子 Li32Si32，单点SCF检查（NSW=0）。**它不是重新弛豫64原子结构**。
3. `03_空位63原子_固定晶格弛豫`：从64原子模型移走一个Li，Li31Si32；固定晶格、优化内部原子（ISIF=2，NSW=40）。
4. `04_NEB末态B00_单点验收`：Li31Si32的路径00末态B，单点SCF及受力验收（NSW=0）；与初态A相同的晶格和化学组成。

所选均为第一次LiSi Agent预验证中实际执行的原始DFT输出，每个子目录保留来源说明（`_SOURCE.txt`）。这是从原始 `01_原始计算输出_01.zip` 中不修改内容地挑出的只读副本。

已排除许可敏感的 `POTCAR`，并省略大型/冗余的 `vasprun.xml`、电荷及波函数文件。要作全面物理验收时，应返回六个原始归档及本轮独立审计。

## 第一小步：结构和弛豫设置（建议10–20分钟）

1. 分别打开前三个目录的 `POSCAR`：读第6、7行元素与数量，确认16 → 64 → 63个原子。
2. 分别打开 `INCAR`：找到 `NSW` 和 `ISIF`。判断哪个执行了全晶格弛豫、哪个只是SCF单点检查、哪个固定晶格做原子弛豫。
3. 对比第二、第三个目录的 `POSCAR` 前三条晶格矢量；思考为什么二者一致。
4. 仅供快速交叉检查：在解压文件夹中运行 `py .\查看数据.py`（无第三方依赖），把程序结果与手动读取对照。

把以下三项结果发回对话即可进入下一步：原子数变化、三次计算的NSW/ISIF含义、64与63原子的晶格是否变化。

## 后两小步（暂不要求一次做完）

- 弛豫与数值收敛：对比 `POSCAR`/`CONTCAR`，理解 `analysis_result.json` 中 `SCF_converged`、`last_frame.Fmax_eV_A`、`n_ionic_frames` 的证据作用。
- 端点核验：检查A与B00均为Li31Si32；晶格一致，原子排序对应，主要差异是一次Li与空位交换；审查能量是否接近及力是否达标。路径选择原理与完整4路径网络属于C1.2.3，不在这里展开。

当前模型来自 `C阶段_2.方案_LiSi预验证后.md`；科研限度是有限超胞、预设中性Li空位，不将其误称为真实LiSi的无条件本征扩散性质。
