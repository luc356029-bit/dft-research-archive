# GitHub publication status

Published to the public repository on 2026-11-14.

## Current repository contents

- 218 files in the GitHub tree.
- 77 Materials Project CIF structures.
- 54 Markdown documents.
- 22 Python scripts.
- 41 JSON records.
- 3 CSV tables.
- 21 additional input/support files.

The repository is organized in the A → B → C1 → supplementary-validation sequence.

## What is included

- A-stage CIF structures, screening method notes, and an API-key-safe screening script.
- B-stage symmetry/pathway notes and the six analysis scripts.
- C1 workflow notes, KMC code, selected VASP input files, analysis JSON, and admission/validation records.
- Supplementary literature comparisons, endpoint/NEB checks, error attribution, migration-time analysis, and provenance manifests.

## What is not mirrored into GitHub

The GitHub tree is a curated public mirror, not a byte-for-byte copy of the 05 ZIP package. Large raw-output files and large nested evidence ZIP bundles have not been uploaded in this pass. The underlying source archives remain in the original Google Drive folders and the separately prepared local package.

The following are also intentionally excluded:
- VASP POTCAR files and embedded copies.
- Third-party publisher PDFs/HTML.
- Foundation-model weights under academic/non-commercial restrictions.
- Any hard-coded Materials Project API credentials.

File integrity, numerical reproduction, and scientific validation are separate claims. The repository does not claim that all calculations have been rerun or independently validated.
