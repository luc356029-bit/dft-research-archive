# POTCAR exclusion

POTCAR files are not included in this public repository. They are licensed VASP datasets and should be obtained through the user's own authorized VASP installation.

The public inputs preserve POSCAR, INCAR, KPOINTS, OSZICAR, selected OUTCAR/CONTCAR records, analysis JSON, and source metadata where available. A clean rerun still requires the correct licensed PAW datasets and VASP version.
