# B — Structure and diffusion pathways

Purpose: convert crystal structures into symmetry-aware candidate Li migration networks and determine the candidate path set for later NEB/AIMD work.

The workflow proceeds through space-group identification, inequivalent Li sites, Li–Li distance shells, the d0 cutoff and geometric dimensionality, physical-hop enumeration, and symmetry reduction into Npath and Ni. The notes preserve the unresolved distinction between the reproduction's candidate-path definition and the paper's reported Npath values.
