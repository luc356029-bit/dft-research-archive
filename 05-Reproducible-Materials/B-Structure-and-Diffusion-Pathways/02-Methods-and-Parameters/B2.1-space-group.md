### 2.输入 、内化 → 实践强化
*吸收LLM的讲解，以自己的方式内化、记录*

**材料层：**
1. 原胞（描述晶体结构的最小重复单元）→ 晶胞（包括但不限于原胞，有时候会因为对称性而人为划定的比原胞大，一般都直接使用晶胞而非原胞）
2. 晶胞胞无限平移 → 晶体（理想晶体是数学上晶胞的无限周期循环，现实是有限的）
3. 晶系（按晶格的几何特征分类，如：立方、四方、正交）→ 布拉维（Bravais）点阵（晶格的14种基本点阵类型，属于某个晶系，如体心、面心立方）→ 晶格（Bravais点阵 + 晶格常数、晶格角 的周期性组合）
4. 晶格+原子种类+原子坐标 → 晶体 → 空间群（晶体经过一系列对称操作之后和原来重叠的操作集合）
5. 晶胞参数（当前选定的晶胞，可能是原胞或者常规晶胞等）= 晶格常数（长度） + 晶格角（角度）

**代码层：**
1. 分析晶体结构对称性 → structure（csv文件中提取出的晶体结构信息，包括晶格、原子种类、原子坐标 ）→ SpacegroupAnalyzer（直接由paymatgen控制）→ spglib（底层库，专门晶体对称性分析）
2. DFT结构优化（弛豫）导致数学上晶格参数并不完美对称 → symprec：对称性分析中允许的最大距离公差； angle_tolerance：对称性分析中允许的最大角度公差
3. structure：.cif文件中提取出的晶体结构信息，包括晶格、原子种类、原子坐标
### 3.实践

**环境配置、文件配置：**
1. 部署pymatgen--读取cif、调用SpacegroupAnalyzer
2. 部署spglib

**运行、对比：**
1. 对LiAl进行验证
2. 科研/--`py .\代码库\B分析\B2.1_结构-空间群.py`
3. 与文章对比，数据相同；调整symprec=0.08/0.1/0.12，angle_tolerance=3/5/7，数据不变，说明不是偶然现象

**源码：**
```python
from pymatgen.core import Structure
from pymatgen.symmetry.analyzer import SpacegroupAnalyzer

# 1. 读取晶体结构
structure = Structure.from_file("cif_files/mp-1067_LiAl.cif")

# 2. 看看 Structure 里实际有什么
print("=== Structure 输入信息 ===")
print("化学式:", structure.composition.reduced_formula)
print("晶格常数 a,b,c:", structure.lattice.abc)
print("晶格角 α,β,γ:", structure.lattice.angles)
print("原子总数:", len(structure))

print("\n原子与分数坐标:")
for i, site in enumerate(structure):
    print(i, site.species_string, site.frac_coords)

# 3. 对称性分析
sga = SpacegroupAnalyzer(
    structure,
    symprec=0.10,
    angle_tolerance=5.0
)

# 4. 输出空间群
print("\n=== 空间群分析 ===")
print("空间群符号:", sga.get_space_group_symbol())
print("空间群编号:", sga.get_space_group_number())
```
