- 循环6/run.py、method.py、core.py、validate.py：最终完整源码及核验。

- 循环6/实验数据/36种材料论文对比.csv：对论文可比较部分分层统计。
- 循环6/实验数据/mp-*.json：完整结构、分组、路径代表与所有成员。
- 循环6/实验数据/全部物理hop/mp-*.csv：端点索引、周期像、路径长度与类别。
- 参考资料/论文表1基准.csv：从原论文核对的38行基准。
- 参考资料/只读源文件初始哈希.json、只读源文件最终核验.json：源文件未改动证据。
- 临时文件：文本提取、报告制作代码与所有页面渲染。
