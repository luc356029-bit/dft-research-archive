# 全部循环简单数据流报告

日期：2026-10-08。起点：用户B分析-2.方案、首次d=3。

## 对比口径
论文表1有38行，本地相同mp-ID为34种，替代结构2种，缺失Li3Al、LiNi3两种。1/2/3为精确数值比较，>3为截尾比较。替代结构单列，不与相同ID的证据强度混同。

## 循环1：首次3D贯通的全局cutoff

`CIF -> Li不等价位点 -> 0.01 A距离壳 -> 完整Li周期图首次维度3 -> cutoff内全部物理hop -> 空间群轨道 -> Npath、Ni`

结果：18/36；相同ID 16/34。

诊断：网络首次贯通不是局域候选路径齐备的充分条件。

## 循环2：每种位点对的最短壳

`CIF -> Li位点等价组 -> 9 A周期hop -> 空间群轨道 -> 无序Li类型对(A,A)/(A,B)/(B,B) -> 每对最短0.01 A轨道壳 -> Npath、Ni`

结果：33/36；相同ID 31/34。

诊断：提高计数匹配，但9 A不足以穷尽大晶胞中的所有类型对，且最短边可局域封闭。

## 循环3：公开算法及邻接/障碍判据对照

`CIF -> DPF局域第二/第三近邻cutoff，或全原子/Li-only Voronoi边，或最短类型对+Gabriel/线段净空 -> 空间群轨道 -> Npath`

结果：DPF规则19/36；全原子Voronoi15/36；Li-only13/36；Gabriel26/36。

诊断：没有稳定优于循环2的统一判据；排除非Gabriel边会删掉论文Fm-3m家族要求的第三类。

## 循环4：自适应搜索和稳健性检查

`CIF -> 标准化原胞 -> 全部类型对最小周期距离决定搜索半径 -> 完整轨道 -> 每对最短壳 -> Npath；容差/维度/官方源码/超胞对照`

结果：33/36；维度36/36；不标准化超胞1/7通过。

诊断：非等轴超胞限制可表示的点群操作；禁止用非标准超胞的对称分类作为正式结果。

## 循环5：冻结候选方案并推广77种

`CIF -> 标准化原胞 -> 自适应类型对半径 -> 无向PBC物理hop -> 完整空间群轨道 -> 每种类型对最短壳 -> Npath_candidate、Ni；旁路输出1D/3D阈值和通道标记`

结果：77/77完成；33/36匹配；NEB/AIMD 36/36。

诊断：记录6个0D候选网络和LiZn13低Li比例，不把候选计数当成输运证明。

## 循环6：最终方案与正式核验

`原胞/常规胞/超胞/平移CIF -> 强制标准化原胞 -> 自适应候选枚举 -> PBC去重 -> 空间群轨道 -> 类型对最短壳 -> Npath_candidate、Ni -> 几何连通性旁路 -> 分流及复核标记`

结果：77/77完成；33/36匹配；晶胞表示27/27；原分类对照6/6；守恒和维度77/77。

诊断：不做材料例外调参；保留3个数值偏差和正文Li9Al4=9的路径身份差异。

## 最终应采用的数据流

主线：只读CIF -> 标准化原胞 -> SpacegroupAnalyzer识别Li位点类型 -> 根据每种无序类型对的真实最小周期距离，自适应确定搜索半径 -> 枚举所有(i,j,R)物理hop -> 反向/PBC去重 -> 完整空间群轨道 -> 每种类型对的最短0.01 A轨道壳 -> Npath_candidate、Ni -> 论文式NEB/AIMD工作量分流。

旁路：完整Li周期图 -> 最低1D与最低3D贯通cutoff、对应Npath；选中候选轨道 -> 周期平移秩、连通分量、Li分数及壳宽敏感性 -> 需补路径/检查障碍的材料标记。

关键区别：自适应搜索半径仅保证类型对被枚举，不是统一的路径筛选cutoff；选中类型对最短壳以后，既不补齐所有更短hop，也不删掉比首次3D cutoff长的代表hop。

## 最终数据与限制

- 36种：33项表格匹配（91.7%）；其中明确数值23/26，>3分类10/10；NEB/AIMD分流36/36。
- 相同ID：31/34匹配（91.2%），明确数值21/24，>3分类10/10，分流34/34。
- 未解释的三项：Li2Ga、Li3In2、Li2Si均算3，论文均为2。未添加手工例外。
- 论文正文Li9Al4=9，本方案15，故AIMD组的>3匹配不能当成具体路径全重现。
- NLi通常主导本方案计数；必须警惕Npath接近NLi*(NLi+1)/2只是类型对覆盖效应。只有不等价轨道壳中多方向并列时才会超过类型对数。
- 4个论文样本（Li3Ga7、Li3Ga14、LiGe mp-9918、LiSi）的最短候选网络为0D；77种内共有6个0D。需补充串联通道后再用于实际长程扩散NEB，不能把1类候选解释为已有贯通通道。
- 53/77按候选工作量进入NEB组，24/77进入AIMD组；LiZn13虽候选1类、几何网络3D，按论文应单独复核/排除其有效通道，不能认为有高离子传输能力。
- 原始CIF与论文VASP全优化结构不同；没有独立验证集，也未计算迁移能垒。
