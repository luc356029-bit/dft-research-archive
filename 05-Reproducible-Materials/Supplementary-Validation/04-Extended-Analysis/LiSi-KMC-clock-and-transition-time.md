# LiSi：KMC时钟、有限迁移时间与尝试频率的适用边界

2026-11-12。复用原模型、原800 K分块及已取得文献；本轮未运行新DFT、AIMD或KMC，没有修改生产代码/速率。本报告补充并限定同日《Em、D、Ea最终差异归因与收尾》中频率线性缩放示例的物理解释。

**结论：当前KMC确实没有单独的“在途时间”；800 K的瞬时、无记忆跳跃近似尚未获得物理验证，有限过渡时间/再穿越是可能的差异来源。但不能因此直接在TST时钟后加一段时间，也不能认定它已经解释D差。** ν整体缩放导致D同比缩放，是当前连续时间马尔可夫跳跃模型（CTMC）内的恒等式；不是任意原子动力学下的恒等式。实际迁移过程时间不等于1/ν。

## 2. 代码到底累计了什么

入口为 `round1/scripts/tracer_kmc.py` 第46行：

```python
time += -np.log(max(v, np.finfo(float).tiny)) / total[old]
```

其中 `total=rates.sum(axis=1)`；每次选一个交换，将Li和空位非折回位移立即更新。累计时间来自指定速率的指数分布，平均为1/R，其中R是当前**整个空位局域构型的总出速率**。它不是每个通道各等待一遍，也不是主导路径1/k的简单相加。空间更新与计时语句的程序先后不代表真实飞行先后。

【本轮新验证】800 K原两种子合计1600万事件、模型时钟累计约13.012微秒，平均每事件0.8132479 ps；由速率直接得到0.8132347 ps，相对差1.63×10⁻⁵，符合随机时钟。**这是模型物理时间单位的一致性，不能证明已与真实MD时钟标定。**

一次“某特定Li的平均跳跃间隔”约103 ps，是人口平均；不能用它代替0.813 ps来论证局域空位构型有充分时间热化。也不能把1/k_AB当成在有其他竞争通道时“首次到达指定B”的完整平均首达时间。

对标准KMC，时钟含义及指数驻留条件见Voter §3–5：系统需要先在盆内失忆，才可用仅依赖当前状态的速率。这是长时粗粒化，而不是删除时间后再任意补回的计时法。[作者预印本](https://www.fml.t.u-tokyo.ac.jp/~izumi/CMS/MC/Introduction_kMC.pdf)

## 3. TST速率、真实过渡路径时间和重复计时

需要分开四个量：

1. **νᵢ**：本项目当前为共同假设10¹³ s⁻¹；谐TST中的ν是初态正常模频率乘积与鞍点稳定模频率乘积之比，包含振动熵信息。它不是迁移原子的单一振动频率，也不是过渡路径的速度。
2. **kᵢ=νᵢexp(−Emᵢ/kBT)**：指定状态定义下的跳跃率近似。本项目没有计算动力学透射系数κᵢ；若其他TST假设成立，常写真实速率kᵢ=κᵢkᵢ,TST。
3. **驻留/失忆时间**：τ_hold是模型离开当前构型之前的保持时间；盆内热化/去相关时间τ_relax是另一个量。失忆和大多数过渡应在远短于平均保持时间的尺度完成，才有充分Markov依据。
4. **过渡路径时间τ_TP**：先定义分离的A/B核心区，再量成功轨迹**最后离开A到首次到达B**的时长；沿途不能重新进入A。其分布依赖核心区边界、势垒形状、质量、摩擦/热浴和实际动力学。

基本TST把正向分割面穿越计为反应事件；若轨迹随后返回，动态修正会降低有效成功率。**这一短时再穿越，与KMC中完成A→B后又发生一次B→A交换不是同一层次。** 后者的几何/示踪回跳相关性已有网络/KMC处理，不能笼统说“所有回跳都被漏掉”。前者和到达B后未失忆导致的连续跳跃，目前未被现有速率验证。相关区别见[Vanden-Eijnden与Tal2005作者摘要](https://pubmed.ncbi.nlm.nih.gov/16292895/)及[Voter §6](https://www.fml.t.u-tokyo.ac.jp/~izumi/CMS/MC/Introduction_kMC.pdf)。

如果由连续MD、完整物理时间和明确状态定义标定有效速率，那么核心区之间的平均耗时可以已经归入粗粒化的保持时间。此时再加τ_TP可能重复计时。反之，如果所用k严格只描述离开A核心前的等待，并且真实过程确有未计入的独立串行过渡段，才可以在**重新定义的半马尔可夫/更新过程**里额外计时。原始TST通量本身既不是“保证含全部到B时间”，也不是“纯等待后必定还缺一段”的证明。

即使按零温NEB曲线估到了鞍点曲率，1/虚频也只是局部不稳定运动的尺度，不能自动等于τ_TP；本项目的负曲率检查更不能提供完整动力学摩擦或边界定义。本文没有采用τ_TP=1/ν，也不将图形反演ν的倒数称作迁移时间。[过渡路径与首达路径定义：Kim与Netz2015](https://arxiv.org/abs/1509.00418)

## 4. 用当前速率检查800 K的时间尺度

当前四条Em为0.2534438、0.2358302、0.2459095、0.4276611 eV。每个Li位点对应四族的出通道数为1、2、1、2，共六条；这由现有轨道简并数得到，没有新做结构映射。

| 温度 | 最低Em/kBT | 总出速率 R /s⁻¹ | 平均模型驻留/ps | 共同ν×0.4后的驻留/ps |
|---|---:|---:|---:|---:|
| 250 K | 10.95 | 5.4043×10⁸ | 1850.36 | 4625.91 |
| 300 K | 9.12 | 3.4773×10⁹ | 287.58 | 718.96 |
| 400 K | 6.84 | 3.5829×10¹⁰ | 27.91 | 69.78 |
| 800 K | 3.42 | 1.22966×10¹² | **0.81323** | **2.03309** |

800 K时三条低势垒为3.42–3.68 kBT，第四条6.20 kBT，不能视作所有通道均处于极高势垒极限。**单看Em≈0.2–0.4 eV不够；必须与T、总出速率、τ_TP和τ_relax一同比较。**

【合理推断】低温下模型驻留明显更长，时标分离比800 K更容易成立；但在没有实际τ_TP/τ_relax的情况下，这不是低温绝对D已验证的证书。800 K需要的是κ/反应通量平台、驻留生存分布和记忆检验；更多同模型KMC种子不能回答这些问题。

没有一个通用“超过若干kBT就必然可靠”的阈值。平均保持0.813 ps既不能证明真实过渡必然太慢，也不能保证足够快；现有证据的正确状态为**800 K粗粒化动力学适用性未验证**。

## 5. “ν×0.4、在途时间不变”是否破坏线性缩放

**在当前CTMC内部不会破坏。** 所有通道速率统一乘α时，事件选择概率、嵌入空间路径及示踪相关性不变；所有指数保持时间变为原来的1/α。故在长时扩散定义下：

**D_CTMC(αk)=αD_CTMC(k)。**

因此ν乘0.4对应平均等待/保持时间乘2.5，而不是乘0.4。如果改变ν时还改变了真实过渡持续时间、摩擦、κ或历史相关性，则已不是单纯的同一个CTMC生成元缩放。

### 仅用于量级判断的“额外串行时间”演示

假设每次离散交换后还要额外耗时τ，且该时间**确实未包含在原速率中**；空间事件序列、分支概率和相关性完全不变，没有重叠或其他并行事件。这是演示假设，不是已验证的LiSi修正。此时长时：

D_serial(k,τ)=D_CTMC(k)/(1+Rτ)，

D_serial(αk,τ)/D_serial(k,τ)=α(1+Rτ)/(1+αRτ)。

| 假设每事件额外τ/ps | D_serial/D_CTMC | 相同τ下ν×0.4导致的D倍率 |
|---:|---:|---:|
| 0 | 1.0000 | 0.4000 |
| 0.05 | 0.9421 | 0.4144 |
| 0.10 | 0.8905 | 0.4281 |
| 0.20 | 0.8026 | 0.4537 |
| 0.50 | 0.6193 | 0.5184 |
| 1.00 | 0.4485 | 0.5978 |

这个演示说明了**条件性非线性**：若额外时间是实在、独立且不随ν变的，真实D未必随ν线性。但不能仅凭这个演示，判定原TST速率应当另加τ，或把表里任何一行当实际LiSi结果。

在此演示中，要使D相对原CTMC减少不超过5%，τ需小于约0.0428 ps（43 fs）；不超过10%需小于约0.0904 ps。这里分母为原CTMC的D，**不是完整物理误差上界**，也没有测得实际τ已小于这些阈值。

若把本项目800 K的2.67672×10⁻⁷降到Kirsch的1.0×10⁻⁷ cm²/s，单靠该额外时间演示需要平均τ≈**1.364 ps**，为原模型驻留时间的1.677倍、占新总时间约62.6%。这已经不能作为“快速过渡、充分稀有事件”下的小修正；如真实情况如此，应重新审视粗粒化状态/速率或采用有记忆动力学，而不是给现有代码悄悄加常数。**1.364 ps是反推所需量，不是估计或测量出的迁移时间，也不证明该机制真实解释差值。**

同日从Kumar图21反演的3.5–6.9×10¹² s⁻¹仍是谐TST前因子的独立量级线索。但它既不提供τ_TP，也没有给本体系κ。此前“频率范围缩放可覆盖文献D”的表述只能保留为**CTMC内敏感性**，不能升级为真实动力学差异归因通过。

### 若未来拿到原轨迹，最低成本应检查什么

1. 核实模拟步长与**实际坐标输出间隔**，不能把正文1 fs步长自动当文件1 fs分辨率；按PBC展开并保持迁移Li身份/空位映射。
2. 定义分离的A/B核心区及中间区；不能只用覆盖所有空间的最近位点标签把过渡瞬间压成零时长。边界需依据振动分布/状态定义并做敏感性检查。
3. 逐条成功事件提取最后离A→首次入B的τ_TP，另记失败返回、连续多跳、到达B后的失忆时间；不能将所有离A的尝试都当成功迁移。
4. 检查驻留生存分布是否存在指数段、出速率是否有稳定平台、下一事件是否依赖进入历史；若做反应通量/κ(t)，需在微观松弛后、下一次稀有反应前有可用的平台窗口。
5. 在统一完整物理时钟上估计MD有效k与D，再决定是否需半马尔可夫表示。由总物理时间得到的有效k不能再无条件加同一段τ_TP。

这是一份拿到数据后的处理标准，不是本轮已执行的动力学验证。

## 7. 适用范围

> 本项目采用连续时间马尔可夫空位交换模型：各事件按指定静态势垒及前因子给定速率，物理时钟以指数驻留时间推进，位置在事件时刻更新。未显式解析过渡路径的持续时间、盆内热化及短时动力学再穿越。本体系800 K下模型平均驻留约0.813 ps，而实际过渡持续时间、失忆时间及透射系数尚未获得，因此时间尺度分离和该温度下绝对速率的物理准确性未得到验证。共同前因子缩放带来的D线性变化仅为固定CTMC内结论，不保证真实AIMD具有同样缩放；未以1/ν估计过渡时间，也未添加无依据的时间修正。报告的统计误差仅覆盖给定模型的KMC采样。

这一局限影响**当前速率目录与瞬时Markov模型对真实800 K动力学的适用性**；不推翻已完成的代码时钟/网络自洽检查，也不使静态Em自动失效。800 K的D差仍是**尚未解释**，新加入“有限过渡、失忆/再穿越和时间粗粒化”作为未量化候选。
