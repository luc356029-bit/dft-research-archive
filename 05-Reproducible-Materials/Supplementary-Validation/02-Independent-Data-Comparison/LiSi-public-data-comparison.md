# LiSi 公开数据对照与差异归因

2026-11-09。对象限定为 mp-795 对应的晶态 I41/a LiSi。沿用首轮已验收 NEB 和 KMC；本次仅下载公开文献/数据、做结构映射及本机低成本 KMC 控制，没有运行新的 DFT/AIMD，没有提交超算任务、修改原始输出或按文献反调参数。

## 结论与验收边界

**找到了有实际检验价值的独立数据，最强的是 Kirsch 等2025的公开原始 NEB。三条跳跃轨道可通过晶体结构一一对应，不再依赖 Kumar 的转述。但目前不能宣布我们的绝对 D 或总体 Ea 已被外部精确验证。**

- 迁移机制/Em：同相的公开计算支持约0.2–0.3 eV的三类低障碍空位跳跃，以及约0.43–0.47 eV的另一类近邻。原始结构映射后三条 Em 相差6.7–49.0 meV；这不是“各条都准确”的证明。
- D：最接近的独立 AIMD 是 Li127Si128、800 K、单中性 Li 空位。若按通常 Li 总 MSD/(6t) 解释，其表值1.0e-7 cm²/s低于我们匹配条件后的约2.67e-7，差约2.68倍。2025 SI Eq.S5尚未取得，故这个比值是**带归一前提的对照，不予绝对 D 一致性验收**。
- Ea：0.250704 eV是我们的300 K局部**空位网络**斜率；Li示踪KMC在250–400 K的拟合是0.251611 eV。尚未找到同时有明确缺陷/频率/统计定义的独立 LiSi 多温度数据来严格检验两者。不能用单个800 K AIMD点求Ea，也不能借用自己的Ea把它外推到300 K再验证自己。
- 本征材料：现有 D 是指定空位浓度及共同假设频率下的条件量。低 Em 不代表热平衡空位丰富或本征 LiSi 快扩散。

## 我们究竟在比较什么

三种量严格分开：

`D_Li* = lim [Σ_i <|Δr_i|²> / (6 N_Li t)]`：全部 Li 原子的示踪/自扩散标量；包括未移动 Li，保留粒子身份与PBC解包裹。

`D_v = lim <|ΔR_v|²>/(6t)`：空位位置的扩散标量。

`Ea_slope(T) = -kB d ln D / d(1/T)`：指定D的局部斜率；不同温区的Arrhenius拟合Ea未必相同。单步NEB的Em也不等于任何定义的总体Ea。

在本项目单空位模型，可写 `D_Li* = [N_v/N_Li] f_Li D_uncorr`、`D_v = f_v D_uncorr`。因此 `D_Li* = [N_v/N_Li](f_Li/f_v)D_v`；相关因子和温度、盒子、速率有关。不能只乘或除一个cv把Li示踪D精确变成空位D。128位点的site fraction是1/128，而粒子人口比是1/127。

首轮基准：PBE/PAW Li_sv、VASP/VTST、Li31Si32中性单空位、固定64原子宿主晶胞；四轨道Em=[.253443805,.235830205,.245909490,.427661095]eV。ν=1e13 s^-1为共同假设，未做Vineyard声子前因子。300 K：D_v=1.69720318e-7；Li示踪D(cv1/32)=(2.01231±.01968)e-9 cm²/s。误差仅KMC 1SE，不含DFT、频率或浓度不确定度。

## 差异的定量拆解：证据、候选原因与不能归因之处

### 1. 温度/浓度不一致：已证明，先纠正比较条件

同一128位点、同一频率/能垒，300→800K的Li D增加约605.24倍。相同温度下32→128位点使D减小：300K为4.55倍、800K为4.39倍。因此原始D300与文献D800直接相除的差值没有误差意义。

浓度转换不是机械除4：精确人口比变化为(1/127)/(1/31)=31/127；300K的f_Li又降低约9.96%。这是本模型内的有限浓度/周期回访效应，不是DFT尺寸收敛证据。

### 2. 三条Em差异：已做控制，解释不了约2.7倍的剩余D差

800K仅换三条Em，Li D增加3.22±.80%（独立误差传播）；原始差距没有缩小。对应空位解析D增加9.85%，体现Li示踪与空位相关性不同。300K空位解析D增加20.71%。这说明在当前图/ν假设下，不能把800K的全部偏差简单归为这三条NEB能垒。

单独替换path00会使D_v在300K增至2.255倍，而单独替换path01会降到.777倍；两个效应部分抵消。**整体接近也可能掩盖逐路径差异**，不能只看总D。

2025未给path03。作为敏感性控制，删掉我们path03令解析D_v在300K下降.249%，800K下降14.57%。这些是空位网络结果，不能直接当Li D修正因子；也不证明其余长路径不存在。

### 3. 尝试频率/有限温动力学：重要未决项，不能靠拟合消除

共同ν线性缩放会原样缩放全部D；ν常数本身不改变固定能垒模型的Ea斜率。若强令我们的800K控制吻合通常口径的1e-7，等效共同ν是3.736e12s^-1。这只是“需要多大尺度改变”的诊断，**不是计算出的Vineyard频率，不采用，也不算验证**。

AIMD包括有限温振动、非谐性、回穿和可能协同运动；我们的KMC用0K静态Em和统一常数ν。没有原始MD跳跃统计、自由能或路径声子前因子，不能单独确认频率或哪种非谐效应导致差值，更不能断言我们的ν应该改成上述拟合值。

### 4. DFT方法与缺陷尺寸：存在真实差异，尚未单因素隔离

2025用CP2K/GTH/DZVP、PBE+D3、Γ点、电子Fermi温度600K，缺陷晶胞先全优化再按实验/计算宿主比缩放。我们用VASP/PAW、PBE无D3、k4、固定宿主胞；NEB缺陷尺寸63对255原子。350Ry电子密度cutoff与520eV波函数cutoff不能直接按数值高低评判。

宿主a/c仅约.18/.21%不同，结构对齐良好；但缺陷场、基组/赝势、D3、k取样、晶胞约束都可能影响数十meV。**尚无控制证明差异主要来自超胞或某个软件/泛函**。64原子“安全隔离空位”仍未证明，必须保留此限制。

### 5. 文献AIMD统计与高温相稳定性：不能被KMC小误差遮住

我们的800K模型每100ps预期仅约123次空位交换；文献三Em且不含第四条的同ν模型约99次。这是模型估计，非对其MD实际跳数的测量。一个空位驱动127个Li，不能把127个Li当成127条独立扩散轨迹。表值若为1e-7，100ps的纯扩散MSD增量仅约.6Å²/Li，需要核热振动平台、线性lag段、回跳、时间原点相关和置信区间。

文献只给100ps分析及舍入表值，公开Zenodo没有MD轨迹；不能量化其误差，也不能仅凭我们KMC 0.5%的SE判定双方统计显著不一致。

Tang2013实测LiSi粉末在约756K出现分解峰；2025根据相图评估作不同稳定性讨论，但也明确固定胞、短时长限制分解观测。因此800K对照应理解为保持I41/a结构的有限时间分支，不能自动代表长期热平衡材料，再无条件外推室温。

### 6. Ea差异：先区分对象、温区、浓度是否随T变化

我们的同一固定图、固定Em和ν，空位网络局部Ea从300K的.250704变为800K的.274629eV，已显示网络组合会产生温度曲率。300–700K离散点的解析空位拟合为.254530eV，400–1000K为.262253eV。它们不是Li示踪Ea，不能拿来替代.251611的250–400K Li拟合。

因此Moon的.306、Kumar的.27与本项目.2507之间差值，可能包含观测对象、拟合温区、逐路径频率和相关性，但现在不能为这些差值分配确定的百分比。匹配温区本身在我们的固定网络内只移动约几至十余meV，并不自动解释全部.055eV差。

热平衡本征D还会包含缺陷浓度随温度变化。只有在简单稀释单空位、指定Li化学势/储库等假设下，才可能近似写Ea≈Ef+Em加上相关/熵贡献；封闭Frenkel模型等不能照搬。不能把文献1.03eV空位形成能直接加到现有条件D上，宣称得到了真实本征Ea。

## 当前能作出的准确性判断与下一步优先级

1. **内部数值实现可靠性增强**：同条件KMC、种子/块长、解析空位网络、原始SHA关联通过本轮核验。它验证计算链，不能替代物理真实性。
2. **机制与Em得到独立外部支持，但有数十meV系统差**：可继续研究空位图；应撤回“Em已完全没问题”的强结论。若目标是D300误差20%，单一主导速率的势垒误差需约kBT ln1.2≈4.7meV；跨方法差显著大于此尺度。
3. **绝对D及总体Ea外部定量验收仍未通过**：不能因差2.7倍“看起来不大”就判准确，也不能据未对齐的旧论文差几个数量级判错误。
4. 最有信息量的下一步是取得2025 SI/MD及逐路径ν，并按同Li-MSD/lag/浓度重算；资料访问目前受robots/Radware影响。另一次浏览器读取因工具不能可靠确认当前URL而被停止，没有绕过验证码或安全限制。
5. 后续DFT若获准，优先同协议对主导path00做更大缺陷胞检查、对初态/鞍点算可靠声子前因子，再决定其余轨道与有限温验证；不先做全材料或长AIMD。上述是建议，本次未启动这些昂贵计算。
