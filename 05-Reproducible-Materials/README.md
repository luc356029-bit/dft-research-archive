## 收录范围与使用

仓库收录了结构、代码、选定输入输出、分析报告及六个补充证据 ZIP；大型原始输出、部分完整归档和原笔记配图尚未收录。完整复算所需文件以各阶段入口列出的实际材料为准。

复算前需按脚本配置依赖与数据路径；A 阶段通过环境变量 `MP_API_KEY` 读取密钥。VASP 与 PAW 数据需自行准备。POTCAR、第三方论文全文及受限模型权重不随仓库分发，第三方材料沿用各自许可；MACE 对应权重为 ASL 学术非商业许可，ænet 代码与权重需分别核对所用版本的许可。参考来源见各报告。

已保存结果可用于核查计算链；完整重算仍取决于相应输入与软件环境。文件校验信息见[校验记录](Supplementary-Validation/05-Provenance-and-Manifests/)，数值一致性和物理验证的范围见各阶段检验报告。
