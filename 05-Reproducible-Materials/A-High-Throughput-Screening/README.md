# A — High-throughput screening

Purpose: retrieve candidate binary lithium alloys and filter out clearly unsuitable compositions before more expensive structural and transport calculations.

The included CIF directory contains 77 structures. The screening record includes the element exclusions and energy-above-hull threshold used in the reproduction. The current public script reads the Materials Project API key from MP_API_KEY; do not hard-code credentials.

The original screening count and the paper's reported count differ. The accompanying notes preserve the observed discrepancy and the follow-up comparison rather than treating the reproduction as an exact match.
