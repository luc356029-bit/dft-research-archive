# 03 · 主要科研推进

围绕候选路径、整体扩散和结果验证，这次复刻形成了四项相互衔接的重要推进。

| 研究主题 | 关键做法 | 代表结果 |
|---|---|---|
| [01 · 候选扩散路径筛选](01-候选扩散路径筛选方法的独立构建.md) | 按距离壳生成候选路径，再检查对称性与周期连通性 | 两类各自只能局部迁移的 LiSi 路径，组合后形成 **三维扩散网络** |
| [02 · 独立 KMC 输运计算](02-独立KMC输运计算与验证.md) | 根据 NEB 能垒模拟 Li 迁移，再求解主方程核对结果 | 250–400 K 的 Li 示踪 **Ea ≈ 0.2516 eV** |
| [03 · 低频路径的输运贡献](03-低频路径的非比例输运贡献.md) | 保持其他条件不变，移除 Path03 | 800 K 下仅占总跳跃次数 **3.29%** 的路径，移除后 D 下降 **32.84%** |
| [04 · 独立文献对照与差异归因](04-独立文献数据对照与差异归因.md) | 在同一模型中，逐条替换为文献能垒 | 用 Kirsch 能垒算出的 Ea 与本项目相差约 **1.41 meV**；Moon 的约 **17 meV** 差异主要来自 Path00 |
