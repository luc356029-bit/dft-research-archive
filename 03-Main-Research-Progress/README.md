# 03 · 主要科研推进

这次复刻中，有几个问题无法直接从文章里找到答案：候选扩散路径怎么选，单条路径的能垒如何变成整体扩散性质，为什么很少发生的跳跃也会明显影响结果，以及怎样判断自己与文献的差异。

下面四篇沿着这些问题展开，记录我如何从文章出发，逐渐形成自己的计算和判断方法。

| 主题 | 推进过程 |
|---|---|
| [01 · 候选扩散路径筛选方法的独立构建](01-候选扩散路径筛选方法的独立构建.md) | 从 Li–Li 距离壳出发，结合空间群和长程连通性，明确 Npath 的选择依据 |
| [02 · 独立 KMC 输运计算与验证](02-独立KMC输运计算与验证.md) | 将 NEB 能垒转为跳跃速率，模拟 Li 迁移，得到 D(T) 和 Ea，并检查计算是否可靠 |
| [03 · 低频路径的非比例输运贡献](03-低频路径的非比例输运贡献.md) | 从事件统计中的疑问出发，通过删去 Path03，观察整体扩散如何变化 |
| [04 · 独立文献数据对照与差异归因](04-独立文献数据对照与差异归因.md) | 对齐路径、模型和统计方式，逐项替换输入，追查 Em、D 和 Ea 的差异 |

原始思考和具体学习过程见 [04 · 研究流程与学习记录](../04-Learning-Notes/README.md)，代码与计算数据见 [05 · 可追溯计算材料](../05-Reproducible-Materials/README.md)。各篇末尾也有对应入口。
