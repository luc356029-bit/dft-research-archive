# 03 · 主要科研推进

围绕候选路径、整体扩散和结果验证，这次复刻形成了四项相互衔接的推进。

| 研究主题 | 关键做法 | 代表结果 |
|---|---|---|
| [01 · 候选扩散路径筛选](01-候选扩散路径筛选方法的独立构建.md) | 距离壳枚举、空间群分类、周期连通性检查 | 两类各自为 0D 的 LiSi 路径，组合后形成 **3D 网络** |
| [02 · 独立 KMC 输运计算](02-独立KMC输运计算与验证.md) | 从 NEB 能垒模拟 Li 迁移，再用主方程交叉验证 | 250–400 K 的 Li 示踪 **Ea ≈ 0.2516 eV** |
| [03 · 低频路径的输运贡献](03-低频路径的非比例输运贡献.md) | 保持其他条件不变，关闭 Path03 | 800 K 下仅占 **3.29%** 的事件，删去后 D 下降 **32.84%** |
| [04 · 独立文献对照与差异归因](04-独立文献数据对照与差异归因.md) | 统一模型，逐项替换外部能垒 | Kirsch 输入重算的 Ea 差约 **1.41 meV**；Moon 的约 **17 meV** 差异主要来自 Path00 |
