# 03 · 主要科研推进

这里精选能代表研究推进质量的关键问题与判断，不重复完整计算记录。每个案例保留问题、关键推理、结果及其适用边界；详细学习过程见 04，计算与证据见 05。

## 核心案例

1. [路径数量不等于长程输运能力](01-路径数量与周期连通性.md)：从候选 hop 计数进一步检查周期网络能否累积净位移。
2. [两个 Ea 必须先统一观测口径](02-活化能的可比性.md)：区分单步 Em、空位局部斜率和 Li 示踪拟合 Ea，并用共同模型比较独立输入。
3. [低频路径不等于低输运贡献](03-低频路径与输运贡献.md)：通过受控删边识别事件频率与扩散贡献之间的差别。

这些案例不是对全部历史工作逐项复述，而是从学习记录与最终证据中提炼的代表性研究判断。
