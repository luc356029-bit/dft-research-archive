
| 名词            | 解释                                                                                                                                                                                                                                                                                                                                                 |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 赝势            | 在计算材料学里，对于原子中那些不怎么主导反应的那一部分，如果我们依然把真实的数据代入进去，计算量会很大，我们只需要采用一种办法让这一部分对于反应的影响和真实情况差不多就行了，这种办法就叫赝势                                                                                                                                                                                                                                                    |
| shell         | shell是计算机里最底层的说人话的语言执行系统，再往下的东西都不说人话，需要由shell转译                                                                                                                                                                                                                                                                                                    |
| slurm         | 超算里的作业调度器，帮助用户提交和管理作业                                                                                                                                                                                                                                                                                                                              |
| bash          | 一种shell，是Linux的默认配置                                                                                                                                                                                                                                                                                                                                |
| sbatch        | 一种用于提交作业的命令                                                                                                                                                                                                                                                                                                                                        |
| 环境变量          | 让系统记住某个路径，当输入路径里的某个文件，系统会挨个去寻找并且打开，就不需要再挨个去敲文件路径了                                                                                                                                                                                                                                                                                                  |
| 文件夹bin        | Linux里专门用来装执行程序（类似于Windows里的.exe）或命令的文件夹                                                                                                                                                                                                                                                                                                           |
| DCU           | Deep Computing Unit（深度计算处理器），就是加速卡的一种，用来加速计算。英伟达的加速卡叫GPU，海光（国产）的加速卡叫DCU                                                                                                                                                                                                                                                                            |
| 栈内存           | 内存有两个部分，一个是栈内存，一个是堆内存，堆内存容量大，但是相比栈内存速度慢很多，vasp计算可能会突然塞进一个100MB的矩阵，需要通过`ulimit -s unlimited`申请较大的栈内存，使用默认栈内存可能会崩溃                                                                                                                                                                                                                                   |
| HSA           | 异构系统架构，AMD推出的一套标准，让CPU和GPU之间更好的协作。<br>常出现于HSA_FORCE_FINE_GRAIN_PCIE=1，可以保证CPU和GPU之间以最精细、最快的方式传输信息                                                                                                                                                                                                                                                  |
| NELM          | 电子自洽迭代的最大步数，VASP 每一次移动原子之前，都要先通过多次迭代让电子达到基态。NELM 就是这个迭代次数的上限。                                                                                                                                                                                                                                                                                      |
| ALGO          | ALGO参数决定了系统如何求解电子波函数，即电子自洽迭代（SCF）的数学算法。有Normal,Fast,VeryFast,All，四个选项                                                                                                                                                                                                                                                                              |
| $VASP_PP_PATH | 一个快捷方式（环境变量），是超算里存放POTCAR（赝势文件）的文件夹                                                                                                                                                                                                                                                                                                                |
| potpaw_PBE    | potpaw：一种赝势格式，波函数处理方式，投影缀加波方法。PBE：交换关联泛函。potpaw_PBE是目前最主流的赝势库                                                                                                                                                                                                                                                                                      |
| 波函数处理         | 波函数就是电子的形态，电子一般以波的形式存在，当观察它时，受到光子波函数的影响，坍缩成粒子状态。<br>波函数处理就是要把波函数给描述出来                                                                                                                                                                                                                                                                              |
| 投影缀加波         | 原子中，内层的电子波函数受到各种力的影响，能量很高，会疯狂震荡，有无数的微小起伏，导致计算机很难精确的描述。<br>外层的电子波函数由于受引力影响比较小，能量低，波动平缓，较好描述。<br>为了减小计算量，就有了投影缀加波的方法：<br> 先将内层的电子虚构为一个平缓的“假波”，采用投影函数，把“假波”投影到内层真实的轨道上，与外层的真实波平滑对接。<br> 但这时算出来的值和真实数据依然是有差值的，因此计算完之后，需要采用缀加的方式，把这个差值补上去                                                                                                               |
| 交换关联泛函        | **交换效应：**自旋相同的电子波函数不能靠太近<br>**关联效应：**电子间会排斥，一个电子运动时，周围的电子会根据它的位置避开它<br>**泛函：**普通的函数是，输入一个数字，输出一个数字。泛函是输入一个函数，输出一个数字<br><br>经过投影缀加波方法处理的波函数，通过计算得到总电子密度，再根据这个电子密度、结合PBE 泛函的数学公式计算出交换关联能<br><br>**为什么需要这个：**<br>我们要做的是模拟材料，要知道电子之间的相互作用，但是如果用电子波函数直接计算，成百上千的电子之间相互作用，计算量大到算不错了，因此有人提出了用电子密度的方式简化这个计算，但是因此会失去一些微观上的效应，交换关联泛函就是用来把失去的效应补上的一种方法<br><br> |
| NEB           | 已知初始状态和末状态（可以通过DFT弛豫来求），可以求出能量最低路径，进而求出对应活化能（反应能垒）                                                                                                                                                                                                                                                                                                 |
| AIMD          | 给一个初始状态和温度，模拟原子的运动轨迹和对应的时间。最终可以得到一个轨迹动画文件                                                                                                                                                                                                                                                                                                          |
| perc（渗流）筛选    | Li离子有不同的扩散路径，一维：一条线，二维：类似于面，可以前后左右移动，不能上下移动，三维：立体的移动路径                                                                                                                                                                                                                                                                                             |
| RMM-DIIS      | 就是INCAR里的ALGO = Fast                                                                                                                                                                                                                                                                                                                               |
| Davidson      | INCAR里的ALGO = Normal                                                                                                                                                                                                                                                                                                                               |
| 展宽            | 模拟时计算机会遇到的问题。电子的能级是一级一级的‘台阶’，调整结构可能会让电子上下反复跳动，展宽相当于把台阶给磨圆了，让电子可以停留在上下的中间位置(模糊中间态，类似于波函数)。                                                                                                                                                                                                                                                          |
| VTST          | 是vasp的一个扩展包，有NEB的功能                                                                                                                                                                                                                                                                                                                                |
| relax_inputs  | 文件名，relax一般是Structure Relaxation（结构弛豫）的简称<br>合起来就是弛豫输入                                                                                                                                                                                                                                                                                             |
| MPRelaxSet    | 类，用来生成vasp的输入文件                                                                                                                                                                                                                                                                                                                                    |
