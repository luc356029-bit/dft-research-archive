1、脚本报错

| 报错信号                                                               | 解释                                                                 |
| ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| invalid syntax                                                     | 意为无效语法，常常表现为语法错误或python版本不对以及少了某个扩展包                               |
| OSError: You do not have the right POTCAR with functional='PBE' …… | pymatgen期望的赝势文件路径与实际路径不符，对于PBE泛函，pymatgen只会去POT_GGA_PAW_PBE里面找赝势文件 |

2、vasp报错集合

| 报错现象                                                                                                                   | 发生场景                   | 根本原因                                                                                                     | 解决办法                                                                                                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HIP ERROR: Error code = 1 并且日志里有大量重复的 running 1 mpi-ranks                                                              | 超算上提交 VASP 的结构弛豫任务     | srun 命令没有正确唤醒 MPI 并行环境，导致 32 个核心变成了 32 个独立的单核程序，同时去抢夺 4 张 DCU 显卡，导致底层驱动崩溃。                               | 读取当前目录官方给的 vasp.slurm 文件，规范硬件调用和mpi分配                                                                                                                                                                                 |
| `The electronic self-consistency was not achieved in the given number of steps (NELM)...`<br>（一个大大的WARNING，NELM警告）<br> | vasp.log文件的最后20行       | 电子自洽场（SCF）循环在规定的最大步数（NELM）内没有达到收敛。默认VASP 最多允许电子迭代 60 次（NELM=60）。如果 60 次还没算准，它就会强行终止这一步，并抛出这个大大的 WARNING。 | **加大步数限制：**在 INCAR 中加上 NELM = 100 或 NELM = 200，多给它一点耐心。<br>**更换对角化算法：**调整 ALGO 参数。比如从 ALGO = Normal 换成 ALGO = Fast 或者 ALGO = VeryFast。<br>**调整混合参数（绝招）：**如果能量在震荡，可以在 INCAR 里加上 AMIX = 0.2，BMIX = 0.0001 来让电子演化得更平缓一点。 |
| num prob                                                                                                               | 可能每隔几十行或几行就有一个，在每行开头位置 | 是 RMM-DIIS 算法的数值不稳定标记                                                                                    | 将ALGO = Fast改为ALGO=Normal                                                                                                                                                                                             |
