### 2.输入、内化 → 实践强化
**材料层：**
1. 设计Li-Li”距离壳“的目的：
B阶段目的是根据扩散路径条数筛选出NEB/AIMD
→扩散路径 简单-NEB/复杂-AIMD，由Li-Li几何距离算出的扩散路径条数可以反应出相对 简单/复杂
→需要选择一个Li-Li几何单次扩散距离上限——截断距离
→取一个能刚好形成Li-Li几何长程扩散的距离
→找”Li距离壳“，截断距离从小壳到大壳取值，直到取到刚好形成长程距离扩散的那个壳，就是我们要找的截断距离
2. 周期像：中心晶胞坐标为（0，0，0），x轴正方向的隔壁晶胞就是（1，0，0），晶胞内部的相同位置的原子（相对于所处晶胞来说）他们的index（索引）也相同。如：Li-1（1，0，0）是Li-1（0，0，0）的周期像
3. 获取Li-Li距离时为什么要看PBC（周期性）边界：边缘的Li和隔壁晶胞的Li可能形成晶胞内没有的扩散路径，
（考虑PBC并不代表一定能形成几何长程扩散）
4. 由于每组等价位点内的原子相对位置情况是一样的，因此每一组Li选一个代表Li位点即可
5. Li-Li距离选取范围：晶胞内代表Li位点为中心的半径6Å的球体，后续如果6Å不够，增加到9、12Å
6. ”Li距离壳“如何得到：
→获得晶胞内（考虑PBC边界）所有代表Li位点周围一定范围内的Li-Li距离
→这些所有距离合在一起从小到大排序，如`2.500，2.504，4.199，4.209，4.300`
→从最小值开始算，≤dmin+0.01Å算一壳层，拿掉这一壳层后，又从新的极小值开始算起+0.01Å。如：第一壳层--`2.500，2.504`，第二壳层--`4.199，4.209`，第三壳层--`4.300`
→取当前壳层内的最大距离dmax作为cutoff，若刚好形成长程扩散，此cutoff就是dmax+10e-8

**代码层：**
1. 计算机计算时的二进制转换，会产生很小的误差，大致在10e-16量级，且多步运算后可能会累加成10e-10/-12量级，
这可能导致在之后的计算，物理上刚好是cutoff距离（应该被考虑的距离）因为浮点误差被舍弃，
可以引入一个足够大来覆盖浮点误差，但对物理误差足够小的常数 ε 隔离误差，
因此我们的cutoff定义为：当前截断距离壳的dmax+10e-7

**源码：**
```python
from pymatgen.core import Structure
from pymatgen.symmetry.analyzer import SpacegroupAnalyzer

SYMPREC = 0.10
ANGLE_TOLERANCE = 5.0

SEARCH_RADIUS = 6.0   # Å
SHELL_TOL = 0.01      # Å
EPS = 1e-7            # Å


def analyze_distance_shells(cif_path):
    # 1. 读取结构
    structure = Structure.from_file(cif_path)

    # 2. 得到对称等价位点
    sga = SpacegroupAnalyzer(
        structure,
        symprec=SYMPREC,
        angle_tolerance=ANGLE_TOLERANCE
    )

    symm_structure = sga.get_symmetrized_structure()

    # 3. 提取 Li 等价组
    li_groups = []

    for group in symm_structure.equivalent_indices:
        group = [int(i) for i in group]

        if structure[group[0]].species_string == "Li":
            assert all(
                structure[i].species_string == "Li"
                for i in group
            )
            li_groups.append(group)

    print("=" * 70)
    print("文件:", cif_path)
    print("化学式:", structure.composition.reduced_formula)
    print("空间群:",
          sga.get_space_group_symbol(),
          sga.get_space_group_number())

    print("\n=== Li 等价组 ===")
    for n, group in enumerate(li_groups):
        print(f"Li{n}: {group}，代表位点 = {group[0]}")

    # 4. 从每一个不等价 Li 代表位点出发，
    #    搜索 SEARCH_RADIUS 内全部 Li 周期邻居
    all_distances = []

    print("\n=== 各代表 Li 的周期 Li 邻居 ===")

    for li_type, group in enumerate(li_groups):
        representative_index = group[0]
        center_site = structure[representative_index]

        neighbors = structure.get_neighbors(
            center_site,
            SEARCH_RADIUS
        )

        print(
            f"\nLi{li_type} 代表位点 "
            f"index={representative_index}"
        )

        for neighbor in neighbors:
            # 只保留 Li 邻居
            if neighbor.species_string != "Li":
                continue

            distance = float(neighbor.nn_distance)

            # 去掉自己本身：
            # index相同且image=(0,0,0)
            image = tuple(int(x) for x in neighbor.image)

            if (
                neighbor.index == representative_index
                and image == (0, 0, 0)
            ):
                continue

            all_distances.append(distance)

            print(
                f"邻居index={neighbor.index}, "
                f"image={image}, "
                f"distance={distance:.10f} Å"
            )

    # 5. 所有距离从小到大排序
    all_distances.sort()

    print("\n=== 全部 Li-Li 距离（排序后） ===")
    for d in all_distances:
        print(f"{d:.10f}")

    # 6. 按 dmax-dmin <= 0.01 Å 聚成距离壳
    shells = []

    remaining = all_distances.copy()

    while remaining:
        dmin = remaining[0]

        current_shell = [
            d for d in remaining
            if d - dmin <= SHELL_TOL
        ]

        shells.append(current_shell)

        # 删除已经归入当前壳的距离
        remaining = remaining[len(current_shell):]

    # 7. 输出距离壳
    print("\n=== Li-Li 距离壳 ===")

    for i, shell in enumerate(shells, start=1):
        dmin = min(shell)
        dmax = max(shell)
        center = sum(shell) / len(shell)
        cutoff = dmax + EPS

        print(f"\nShell {i}")
        print(f"成员数: {len(shell)}")
        print(f"dmin   = {dmin:.10f} Å")
        print(f"dmax   = {dmax:.10f} Å")
        print(f"center = {center:.10f} Å")
        print(f"cutoff = {cutoff:.10f} Å")


# 第一轮：LiAl
analyze_distance_shells(
    "cif_files/mp-1067_LiAl.cif"
)
```
