### 2.输入 、内化 → 实践强化

**材料层：**
1. 单路径能垒Ea，i ——某次跳跃的能量门槛
2. 总体活化能Ea ——整体扩散速度对温度的敏感性（（ln D) 对 1/T 的拟合直线斜率）
并不存在能描述材料总体扩散能垒的单一门槛，只是总体等效活化能
3. 扩散系数D ——粒子的扩散速度，单位cm²/s
与 路径、能垒、跳跃频率、可跳跃的缺陷数量 等有关

**算法层：**
- 文章：
结构+候选路径
→ NEB单路径的 Ea，i 
→ 路径数、跳跃距离 加权得总体Ea → 通过扩散频率、距离等参数得D300
- 自定义：
结构+一个Li空位
→ 4类候选Npath
→ NEB分别计算得4条路径的Ea
→ 4 path Ea+扩散网络+KMC 模拟位移 得到D（T）
→ 拟合直线斜率 得到总体Ea
