# DFT 复刻：方法论与研究记录

本仓库记录了近几个月借助 LLM 推进 DFT 复刻项目的过程，分为以下五部分。

**01、02 整理实践中形成的底层逻辑与方法论，可广泛迁移到其他领域**；**03、04、05 保留 DFT 复刻的具体内容**，分别为主要进展、项目笔记与可追溯的计算材料。

## 复刻主题

研究围绕**二元锂合金筛选与 LiSi 空位扩散**展开，涵盖候选结构筛选、迁移路径分析、NEB 能垒计算、KMC 输运分析及文献对照。
